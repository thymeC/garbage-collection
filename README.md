# 垃圾回收站

给想骂人但不能骂的人——一个合法、无害、带点艺术感的情绪出口。

## 痛点

遇到奇葩同事、客服、前任时，很想输出垃圾话，但后果严重；憋着又内伤。本产品提供一个可宣泄又安全的替代方案。

## 产品定位

网页是一个**霓虹赛博风**的「垃圾回收站」（品牌名不含「赛博」二字，仅体现在视觉风格上）。用户可以把想说但不能说的话倒进来，由系统完成无害化处理，并获得情绪释放与仪式感反馈。

## 核心玩法

1. 在输入框写下任何你想骂的话（最多 500 字）。
2. 点击 **♻ 回收**。
3. 回收站用**机械感语音**复述你的话；敏感词在**画面上**被替换为 `哔——`、`哔哔——` 或 **🌼**（🌼 为「小黄花」的 emoji 替代，不出现文字「小黄花」）。
4. 敏感词在**语音上**只播放 **哔** 音效，**不朗读**替换文案（不念「哔——」，也不念「小黄花」）。
5. 处理结束后弹出 **情绪干净证明**，例如：「您的负能量已安全降解，污染指数降低 19%。」（脏词越多，显示降幅越高，上限约 97%。）
6. 可选功能见下方。

## 功能需求

### 必须实现

| 功能 | 说明 |
|------|------|
| 霓虹 UI | 粉 / 青 / 紫霓虹色、网格背景、扫描线、赛博面板样式 |
| 脏话过滤 | 中英文敏感词库；命中后随机视觉替换 |
| 语音复述 | Web Speech API，偏低沉机械感；仅朗读未过滤正文 |
| 哔声替代 | Web Audio 方波哔声；敏感词处只哔、不 TTS |
| 情绪干净证明 | 降解完成后的证书卡片，含污染指数与编号 |
| 输入待回收物质 | 主输入区文案与占位提示 |
| 降解舱 | 回收过程状态动画与无害化结果展示 |

### 可选开关

| 功能 | 说明 |
|------|------|
| 随机匿名公开 | 将**无害化后**的文本发到「匿名共情墙」；当前为浏览器 `localStorage` 本地存储，无后端 |
| 和解模式 🌹 | 把原文转写为玫瑰花式温柔文案，形成强烈反差幽默 |

### 文案与品牌

- 页面标题、主标题：**垃圾回收站**（不使用「赛博垃圾话回收站」等带「赛博」的标题）。
- 副标题示例：给想骂人但不能骂的人 · 合法情绪降解终端 v2.077
- 主按钮：**♻ 回收**
- 页脚说明：本回收站不存储原始脏话 · 仅本地演示 · 污染指数纯属娱乐

### 音频规则（重要）

- **画面**：敏感词 → `哔——` / `哔哔——` / 🌼 / 🌼🌼（随机）。
- **声音**：敏感词 → 仅哔音效（时长可随原词长度略增）；**禁止**对替换符做语音合成。
- **正文**：机械感 TTS 朗读未被过滤的片段。

## 为什么可能火

- 提供合法、无害、甚至带点艺术感的情绪出口。
- 很多人会为了听「哔」音效而反复尝试。
- 「和解模式」把脏话翻成玫瑰文案，反差强、易传播。

## 后续可扩展（未实现）

- 赛博和解模式深化：更智能的「玫瑰花」翻译。
- 一键生成可分享的情绪证明图片。
- 更大脏词库 / 多人实时共情墙（需后端 API）。
- 线上部署与真实匿名围观。

## 本地运行

单文件静态站点，无构建步骤。

```bash
cd garbage-collection
python3 -m http.server 8765
```

浏览器打开 `http://localhost:8765`，或使用 VS Code / Cursor 的 **Live Server** 扩展预览 `index.html`（推荐，便于语音与音频 API 正常工作）。

## 技术栈

- 单页 `index.html`（内联 CSS + JavaScript）
- 字体：Orbitron、Noto Sans SC（Google Fonts）
- 语音：`speechSynthesis`
- 哔声：`AudioContext` 振荡器
- 共情墙：`localStorage`（key: `garbage-recycle-wall`）
